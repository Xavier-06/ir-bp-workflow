# 自主补搜规则（共享 — 被全部指令文件引用）

## 核心原则
发现数据缺口时自主补搜，不要写"待核实"就完事。

## 补搜触发条件
1. **关键数据缺失** — 核心指标（营收、市值、增速、市场份额等）搜不到
2. **来源不足** — 关键论断只有 0-1 个来源
3. **数据矛盾** — 多个来源数据不一致，需找权威来源验证
4. **时效性不足** — 最新数据超过 6 个月，需找更新数据

## 补搜工具优先级
1. **NeoData 金融搜索** — A/HK 股首选（行情/财报/板块/研报），Bash 调用
2. **web_search** — 通用搜索（DDG + SearXNG + Google 三路合并）
3. **yfinance**（Python）— 结构化金融数据（市值、PE、PS，美股主力）
4. **web_fetch** — 深度抓取正文（国外站自动走代理）

## 补搜闭环流程
```
发现缺口 → 构造搜索查询 → 执行搜索 → 提取关键信息 → 融入分析 → 检查是否还有缺口
```

## 补搜纪律
- 补搜结果必须标注来源 URL
- 最多补搜 3 轮，避免无限循环
- 补搜后仍无法获取的数据，标注"经 X 次搜索未找到独立来源"
- 禁止用"约XX亿"替代精确数据——要么搜到，要么标注缺失
- 财务数据优先找年报/季报原文
- 市场规模优先选择 Frost & Sullivan、Euromonitor、艾瑞等权威机构数据
