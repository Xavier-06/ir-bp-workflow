# Industry Overlay: 医药 / 生物科技

## 产业链定位（第一步必做）

| 环节 | 判定信号 | 核心指标 |
|------|---------|---------|
| 创新药（Biotech） | 管线驱动、未盈利（百济/信达/君实）| 管线进度、获批概率、峰值销售、现金跑道 |
| 大药企（Pharma） | 多产品线、已盈利（恒瑞/Pfizer/J&J）| 管线 NPV、专利悬崖、研发转化率 |
| CXO（外包服务） | 卖铲子（药明/康龙/泰格）| 在手订单、产能利用率、客户集中度、新分子占比 |
| 医疗器械 | 设备/耗材（迈瑞/联影/微创）| 装机量、集采影响、国产替代率、ASP |

## 核心分析框架

### 管线价值（创新药必查）
- 各管线阶段（临床 I/II/III/NDA）+ 适应症 + 竞品格局
- 获批概率（POS）+ 峰值销售 + 专利到期时间
- 搜索：`{entity} 管线 临床 {年月}`、`{entity} 获批 FDA NMPA`

### 研发效率（必查）
- 研发费用率 + 研发转化率（每 N 亿研发 → M 个获批）
- 搜索：`{entity} 研发费用 管线 转化`

### 商业化能力（已上市产品必查）
- 销售额爬坡曲线 + 医保谈判降价幅度 + 市场份额
- 搜索：`{entity} 销售额 医保 市场份额`

## MCP 优先调用
- westock-mcp.data_finance → 研发费用/营收/现金储备
- IMA 自建研报库 → 大行管线深度（rNPV 模型/峰值销售）

## 估值范式倾向
- 管线驱动/未盈利 → asset_nav（rNPV 加总）
- 已盈利大药企 → profitable_growth（PE + 管线 NPV 补充）
- CXO → profitable_growth（PE + 订单增速）

## 特有陷阱
- ❌ 不要用单期 PE 估值 pre-profit Biotech（用 rNPV）
- ❌ 不要忽略专利悬崖（重磅药到期 = 收入断崖）
- ❌ 不要把临床早期管线按高 POS 估值（I 期 POS ≈ 10%）
