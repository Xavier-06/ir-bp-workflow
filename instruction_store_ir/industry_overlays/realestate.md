# Industry Overlay: 房地产 / REITs / 基础设施

## 产业链定位（第一步必做）

| 环节 | 判定信号 | 核心指标 |
|------|---------|---------|
| 物流/产业地产 | 仓储/产业园（普洛斯/中电建/万纬）| 出租率、租金增长、cap rate、NAV |
| REITs | 上市 REITs（中金普洛斯/华安张江）| 分派率、FFO、cap rate、底层资产质量 |
| 住宅开发 | 拿地/销售（万科/保利/华润置地）| 销售面积/金额、拿地强度、净负债率、现金短债比 |
| 基建/工程 | EPC/建设（中国建筑/中国中铁）| 新签订单、收入确认、应收账款、PPP 敞口 |

## 核心分析框架

### 资产价值（REITs/物流必查）
- 出租率 + 租金增速 + 加权平均租期（WALE）
- cap rate 趋势（与国债利差）+ NAV 推导
- 搜索：`{entity} 出租率 租金 {年月}`、`{entity} cap rate NAV`

### 财务安全（住宅开发必查）
- 净负债率、现金短债比、剔除预收款资产负债率（三道红线）
- 融资成本 + 融资渠道通畅度
- 搜索：`{entity} 净负债率 现金短债比`、`{entity} 融资 成本`

### 销售与回款（住宅开发必查）
- 月度销售面积/金额 + 同比
- 回款率 + 拿地强度（拿地/销售比）
- 搜索：`{entity} 销售额 {年月}`、`{entity} 拿地 回款`

## MCP 优先调用
- westock-mcp.data_finance → 资产负债率/现金/融资成本
- IMA 研报库 → 大行地产/REITs 深度（NAV/cap rate）

## 估值范式倾向
- REITs/物流/基础设施 → asset_nav（NAV / cap rate 推导）
- 住宅开发 → asset_nav（NAV 折价）/ PB
- 基建工程 → profitable_growth（PE + 订单增速）

## 特有陷阱
- ❌ 不要用 PE 估值地产开发商（用 NAV 折价 / PB）
- ❌ 不要忽略表外负债（合联营项目、明股实债）
- ❌ REITs 分派率 ≠ 收益率（要扣资本利得/损失）
