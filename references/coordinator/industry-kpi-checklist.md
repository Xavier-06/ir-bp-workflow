# 行业特定 KPI 清单

> 供数据收集/行业分析/商业模式/财务分析 Agent 引用
> 按标的所属行业，必须获取以下特有指标

---

## 新消费 / IP 经济

| KPI | 定义 | 数据来源 |
|-----|------|---------|
| IP 收入集中度 | Top 3 IP 占总收入% | 年报/招股书 |
| IP 生命周期 | 各核心IP的推出年份+收入趋势 | 年报+WebSearch |
| 复购率 | 回头客购买占比 | 公司IR/投资者日 |
| 单店UE | 单店月收入/毛利/回收期 | 招股书/年报 |
| 同店增长率(SSSG) | 同店YoY营收增速 | 季报 |
| 海外单店收入 | 海外门店平均收入 vs 国内 | 年报分部数据 |
| 门店总数 + 净增 | 国内/海外分别 | 季报 |
| SKU 数量 | 在售SKU + 新SKU上市节奏 | 年报/官网 |
| 供应链集中度 | Top 3 供应商占比 | 年报 |
| 库存周转天数 | 存货周转 | 年报 |

## 使用方式

各 Agent 在分析对应行业标的时，必须：

1. **数据收集**（phase04 研究计划子代理产出 enriched_data_pack）：从本清单中选择对应该行业的 KPI，作为数据采集的必查项
2. **行业分析 Agent（step1_industry）**：在竞争格局对比中加入行业特定 KPI 对标
3. **商业模式 Agent（step2_biz）**：UE 模型和分析维度按行业 KPI 清单调整侧重
4. **财务分析 Agent（step3_finance）**：在分业务线利润率和营运效率中纳入行业特定指标

**如果某 KPI 的数据无法获取**：标注"公司未披露[X指标]"并说明该指标的重要性。
