# 研报叙事结构模板

> 供差异化洞察 Agent（step6_insight）和文档汇总 Agent（step8_master）引用
> 解决报告"有数据没叙事"的核心问题

---

## 强制叙事链（铁律）

每份研究报告必须能回答以下 **5 个问题**：

```
1. 这篇报告的「一句话投资判断」是什么？
   → 能在电梯里说完的一句话（≤ 40 字）

2. 市场共识是什么？
   → 3 个具体数字（如"一致预期2026E营收500亿，净利率15%，目标价180元"）

3. 我的判断和共识哪里不同？
   → 量化差异（如"我的营收预测高8%，因为XX业务未被充分定价"）

4. 我最晚什么时候被证明是对的？
   → 具体日期或事件（如"2026Q2财报发布"、"竞品X上市"）

5. 如果错了，怎么止损？
   → 具体价格或条件（如"跌破130元"、"营收增速<15%"）
```

**5 个问题有一个答不出来 → 报告不通过。**

## 差异化洞察叙事框架（step6_insight 专用）

### 三层叙事分析

#### 第1层：市场当前在讲什么故事？
- 当前叙事（1-2句）
- 这个叙事的核心假设
- 叙事牢固度（高/中/低）
- 什么数据会强化这个故事
- 什么数据会动摇这个故事

#### 第2层：这个故事哪里有漏洞？
- 市场忽略/低估/高估了什么
- 为什么市场会忽略？（信息不对称？短期主义？偏见？）
- 我看到了什么市场没看到的

#### 第3层：下一个叙事是什么？
- 如果我的判断是对的，市场会讲什么新故事
- 叙事切换的触发条件是什么
- 切换后估值框架会怎么变（PE→PS？PEG？SOTP？）

## 报告正文叙事结构（step8_master 统稿顺序）

```
第1页：投资摘要（上述模板）
第2-3页：行业分析（市场规模 + 竞争格局 + 公司定位）
第4-5页：商业模式（UE模型 + 护城河 + 供应链/渠道）
第6-7页：财务分析（价值创造诊断 + 盈利质量 + 业务线拆解）
第8-9页：预测与估值（三层框架 + DCF + 可比估值）
第10页：管理层（执行力 + 治理 + 激励一致性）
第11页：差异化洞察（预期差 + 叙事层 + 空头拆解）
第12-13页：风险与催化剂（关联矩阵 + 压力测试 + 情景分析）
第14页：宏观环境（五大维度评分 + 对标的传导）
附：来源附录（完整引用列表）
```

## 统稿后强制自检（step8 必须执行）

```
报告完成后，逐条回答：

□ 1. 一句话投资判断写在第1页了吗？
□ 2. 三层估值框架数字清晰吗？
□ 3. 我与市场的三个不同，每个都有量化差异吗？
□ 4. 催化剂时间线有具体月份/季度吗？
□ 5. 止损条件有具体价位吗？
□ 6. 空头论点被拆解了吗？
□ 7. 风险关联矩阵和压力测试有量化吗？
□ 8. 整篇报告的"共识→差异→证据→证伪→止损"逻辑链完整吗？
```

**8 项中 ≥ 7 项通过，报告才能交付。**

## 常见叙事缺陷（反例）

| 缺陷 | 例子 | 修正 |
|------|------|------|
| **没有立场** | "公司具有投资价值，但要注意风险" | 必须选边：看多/看空，给出明确目标价 |
| **共识模糊** | "市场普遍看好" | 必须给出3个具体数字（营收/利润率/目标价的一致预期） |
| **差异不量化** | "我们更乐观一些" | 必须说"我们高X%，因为..." |
| **没有止损** | 只看好不设止损 | 必须有具体价位或条件 |
| **叙事空洞** | "公司基本面良好" | 必须说清楚"公司在增长/转型/改善的什么阶段" |
| **两头下注** | "可能涨也可能跌" | 必须给出概率加权的判断 + 置信度 |
