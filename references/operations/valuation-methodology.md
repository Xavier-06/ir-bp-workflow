# 估值方法论参考 — 三层估值框架

> 本文件定义投研管线的标准化估值方法论。适用于所有标的，不含任何公司特定硬编码。
> step6b_valuation 子代理在开始估值分析前必须读取此文件。

---

## 一、方法论总览：三层估值框架

对于**多业务线、有新兴技术业务（如AI/自动驾驶/机器人等）的复合平台型公司**，传统"核心PE + 高增长PS"的两段式SOTP已不充分。需要升级为三层框架：

```
总股权价值 = 第一层(SOTP底盘) + 第二层(单位市值锚校准) + 第三层(新兴业务独立估值) + 净现金/投资 ± 协同调整
```

### 三层分工

| 层级 | 方法 | 回答的问题 | 适用条件 |
|------|------|-----------|---------|
| **第一层：SOTP 底盘** | 分业务 PE/PS/EV-EBITDA | "成熟业务+高增长业务，最低值多少钱？" | 所有多业务线公司 |
| **第二层：单位市值锚校准** | 对标行业龙头的单产/单量估值 | "生态质量、品牌力、成长斜率有没有在倍数里体现？" | 有明确行业对标龙头时 |
| **第三层：新兴业务独立估值** | ARR/PS/远期PE/设备授权等 | "新兴业务到底是0，还是一项可单列的战略资产？" | 标的有独立投入、产品成型、初步商业化、生态承接场景时 |

### 判断是否需要第三层

当标的的新兴业务同时满足以下**四个条件**时，必须单独估值，不能继续埋在其他业务里：

1. **独立投入足够大** — 研发/资本开支占收入比例显著
2. **产品已成型** — 有可交付的产品/服务，不是纯概念
3. **商业化已起步** — 有初步收入或明确的变现路径
4. **生态承接场景清晰** — 可嵌入公司现有业务体系，有协同效应

### 1.1 业务混合体强制判定（估值前必做）

在开始任何估值计算之前，必须先完成以下分类判定：

#### 判定标准

满足以下**任意2项**即为"业务混合体"，**必须使用SOTP为主方法（权重≥60%），DCF仅作为辅助（权重≤20%）**：

1. **业务线≥3条**，且各业务线收入占比均≥10%
2. **业务线间毛利率差距>30pp**（如硬件10% vs 互联网76%）
3. **不同业务线处于不同生命周期**（成熟期+高成长期+投入期并存）
4. **存在平台型高毛利业务**（毛利率>50%）与硬件低毛利业务并存

#### 小米集团判定示例

| 判定项 | 小米实际 | 结果 |
|--------|---------|------|
| 业务线数量 | 4条（手机、IoT、汽车、互联网） | ✅ 满足 |
| 毛利率差距 | 互联网76.9% vs 手机~10%，差距>60pp | ✅ 满足 |
| 生命周期混合 | 手机成熟期 + IoT成长期 + 汽车投入期 + 互联网平台期 | ✅ 满足 |
| 平台高毛利+硬件低毛 | 互联网76.9% + 手机10.1% | ✅ 满足 |

**判定结论**：小米是典型"业务混合体"，DCF单一WACC无法区分业务风险。强制SOTP为主。

#### 业务混合体的SOTP执行规范

```
估值 = Σ(各业务线独立估值) + 净现金 + 协同溢价 - 重复计价

强制输出：
├── 业务线1（成熟硬件）：净利润×PE(12-18x)
├── 业务线2（高增长硬件）：收入×PS(1.0-3.0x) 或 净利润×PE(18-25x)
├── 业务线3（互联网/平台）：净利润×PE(25-35x) ← 高毛利溢价
├── 业务线4（新兴/AI）：【第三层独立估值】
├── 净现金/投资：+净现金
└── DCF仅做交叉验证（权重≤20%），标注终值占比
```

#### 反例（什么情况下可以用统一DCF）

- 单一业务公司（如纯粹的芯片设计公司）
- 业务线高度同质化（如多品牌消费品，毛利率差<10pp）
- 所有业务线处于同一生命周期阶段

**不符合以上条件 → 必须SOTP。没有例外。**

## 二、第一层：SOTP 底盘

### 核心逻辑

将公司业务线拆分为**成熟利润池**和**高增长收入池**，分别用不同倍数定价。

| 业务类型 | 估值方法 | 倍数区间参考 | 说明 |
|---------|---------|------------|------|
| 成熟业务（稳定盈利） | PE | 12x-25x（视行业） | 基于经调整净利润 |
| 高增长业务（收入高增但利润波动） | PS / EV-Revenue | 0.5x-5x（视行业） | 基于收入 |
| 亏损业务 | PS / 最近融资估值 | 视阶段 | 亏损时PE无意义 |
| 互联网/平台业务 | PE 或 分部估值 | 15x-40x | 高毛利业务可给更高PE |

### SOTP 计算模板

```
业务线A估值 = 业务线A净利润 × PE倍数
业务线B估值 = 业务线B收入 × PS倍数
...
SOTP总估值 = Σ(各业务线估值)
```

### SOTP 的局限性

1. 默认新兴业务不是独立资产，只是"创新业务的一部分"
2. 无法精确刻画跨业务协同溢价
3. 对新兴技术带来的ASP提升、生态粘性上升反映不足

**因此 SOTP 是底盘，不是全部。必须配合第二层和第三层。**

## 三、第二层：单位市值锚校准

### 核心思想

对于生态型公司，单纯看PE/PS容易失真，因为不同公司的每一单位产品所承载的生态价值不同。需要用行业龙头为标尺，校正估值倍数。

### 适用条件

- 标的与某行业龙头有明确的业务对标关系
- 可获取龙头公司的单产/单量数据

### 方法一：硬件产品线对标（适用于手机/消费电子/IoT）

**公式**：
```
对标市值 = 行业龙头单机市值 × (标的单机利润 / 龙头单机利润) × (1+g_标的) / (1+g_龙头) × 标的销量 × 上市地折价修正
```

**其中**：
- 行业龙头单机市值 = 龙头市值 ÷ 龙头出货量
- 标的单机利润 = 标的该业务线净利润 ÷ 标的出货量
- g = 预期收入/利润增速
- 上市地折价修正 = 流动性、监管、地缘风险折价（通常 0.8-1.0）

**操作步骤**：
1. 获取行业龙头市值、出货量、利润数据
2. 计算龙头单机市值和单机利润
3. 获取标的对应数据
4. 计算对标市值
5. 与 SOTP 结果交叉验证

### 方法二：高增长产品线对标（适用于汽车/新能源/机器人等）

**公式**：
```
对标市值 = 行业龙头单车/单台市值 × (标的单车毛利 / 龙头单车毛利) × (1+g_标的) / (1+g_龙头对应阶段) × 销量修正
```

**其中**：
- 行业龙头单车市值 = 龙头该业务线市值 ÷ 龙头交付量
- 标的单车毛利 = 标的该业务线毛利 ÷ 标的交付量
- 销量修正 = 考虑产能爬坡、订单可见性等

### 方法三：平台型对标（适用于互联网/SaaS/生态型公司）

**公式**：
```
对标市值 = 行业龙头单用户市值 × (标的ARPU / 龙头ARPU) × (1+g_标的) / (1+g_龙头) × 标的用户数
```

### 单位市值锚的局限性

1. 不能完整表达生态协同价值
2. 不能充分反映研发、资本开支、折旧、债务结构差异
3. 不能精细表达"暂时收入小、但重塑全生态"的新兴资产

## 四、第三层：新兴业务独立估值

### 4.0 AI模型业务强制识别规则

当标的公司满足以下**任一**条件时，AI模型业务必须启动第三层独立估值，不可埋入其他业务线：

#### 触发条件（满足任一即触发）

1. **自研大模型公开发布**（有明确模型名称、参数量、榜单排名）
2. **AI Agent产品已发布或封测**（如移动端Agent、桌面Agent）
3. **AI研发投入占收入比≥5%** 且 有明确AI战略（公告/财报/投资者日）
4. **AI业务已嵌入核心产品线**（如AI手机、AIoT、AI汽车）

#### 小米集团AI业务触发判定

| 触发条件 | 小米实际 | 结果 |
|----------|---------|------|
| 自研大模型 | MiMO大模型，全球排名第8 | ✅ 触发 |
| AI Agent产品 | Xiaomi miclaw移动端Agent封测 | ✅ 触发 |
| AI研发投入 | 2026-2028年AI投入600亿元，占收入比~4-5% | ✅ 触发 |
| 嵌入核心产品 | AI手机/AIoT 10亿连接/智能座舱 | ✅ 触发 |

**结论：强制启动第三层。**

#### AI业务四法交叉验证（权重调整）

| 方法 | 公式 | 权重 | 对AI业务微调 |
|------|------|------|------------|
| ARR倍数法 | AI业务ARR × ARR倍数 | 25% | ARR含API调用+Agent订阅+模型授权 |
| PS法 | AI业务收入 × PS倍数 | 20% | PS参考AI实验室行情 |
| 远期PE折现 | 远期净利润 × PE / (1+r)^n | 25% | 折现率15-20%（高风险） |
| 设备终端授权法 | 设备量 × 授权费/台 × PS | 20% | 有硬件生态时必用 |
| AI实验室融资锚定 | 按技术能力对标打折 | 10% | Anthropic/OpenAI估值 × 嵌入折扣 |

### 适用判断

当新兴业务满足"四要素"（独立投入大 + 产品成型 + 商业化起步 + 生态承接清晰）时，必须单独估值。

### 四种估值方法交叉验证

#### 方法A：ARR 倍数法（适合商业化早期）

**适用条件**：有初步收入（订阅/API/授权等），但尚未规模化盈利

**公式**：
```
新兴业务估值 = ARR × ARR倍数
```

**ARR 构成**（视业务类型）：
- 订阅收入（SaaS/会员）
- API 调用收入
- 企业部署/私有化收入
- 开发者平台收入
- 公司内部模拟结算（将新兴能力嵌入其他业务线的隐含价值）

**ARR 倍数参考区间**：
| 阶段 | ARR 倍数 | 说明 |
|------|---------|------|
| 早期（ARR < 1亿美元） | 80x-150x | 高增长预期 |
| 成长期（ARR 1-5亿美元） | 40x-80x | 收入验证期 |
| 成熟期（ARR > 5亿美元） | 20x-40x | 盈利能力显现 |

**⚠️ ARR 法适合做区间法和敏感性分析，不适合作为唯一单点估值。**

#### 方法B：PS 法（适合收入开始显性化）

**适用条件**：新兴业务收入已单独披露或可合理拆分

**公式**：
```
新兴业务估值 = 新兴业务收入 × PS倍数
```

**PS 倍数参考**：
| 类型 | PS 倍数 | 说明 |
|------|---------|------|
| AI 平台型公司 | 10x-30x | 如 OpenAI、Anthropic 口径 |
| AI 企业解决方案 | 5x-15x | 如第四范式 |
| AI 应用型公司 | 3x-10x | 商业化验证后 |

**PS 法适合作为第二验证框架，而非唯一主方法。**

#### 方法C：远期 PE 折现法（适合终局思考）

**适用条件**：需要回答"如果新兴业务最终稳定盈利，值多少钱"

**公式**：
```
新兴业务估值 = (远期目标年净利润 × 目标PE) / (1 + WACC)^n
```

**参数参考**：
- 远期目标年：通常取 3-5 年后
- 目标 PE：25x-35x（成熟科技平台）
- WACC：12%-18%（高风险折现）

**⚠️ 此方法对远期假设极度敏感，适合作为上限估值的中长期锚，不适合作为当前唯一主估值法。**

#### 方法D：设备/终端授权法（适合有硬件生态的公司）

**适用条件**：新兴业务可嵌入公司现有硬件/设备生态，按设备量收费

**公式**：
```
潜在年收入 = 覆盖设备量 × 每台设备年授权费
新兴业务估值 = 潜在年收入 × PS倍数 或 远期PE折现
```

**此方法的意义**：说明新兴业务的估值上限，不应仅参考纯软件/纯模型公司，而应参考"技术×终端生态"的平台型估值。

### 四法交叉验证输出

| 方法 | 保守 | 基准 | 乐观 | 权重建议 |
|------|------|------|------|---------|
| ARR 倍数法 | — | — | — | 30% |
| PS 法 | — | — | — | 20% |
| 远期 PE 折现 | — | — | — | 20% |
| 设备/终端授权法 | — | — | — | 15% |
| 分析师/市场共识 | — | — | — | 15% |

## 五、总估值公式与防双重计价

### 完整公式

```
总股权价值 = V_成熟业务 + V_高增长业务 + V_新兴业务显性价值 + V_净现金/投资 + ΔV_新兴业务隐性协同 - ΔV_重复计价
```

### 新兴业务价值拆分

**显性价值**（能直接落到收入上的部分）：
- 新兴业务自身的订阅/API/授权收入
- 独立可识别的商业化收入

**隐性价值**（通过提升其他业务估值实现）：
- 产品 ASP 提升
- 用户 ARPU 提升
- 生态粘性增强带来的 PE 上修
- 毛利率结构改善

### 防双重计价规则

新兴业务的价值会同时体现在：
1. 新兴业务自身的 ARR/PS 估值
2. 成熟业务的 PE 提升
3. 高增长业务的 PS 提升

**因此必须明确拆分**：
- 新兴业务独立估值 = 显性价值（直接收入）
- 成熟/高增长业务的估值倍数调整 = 隐性价值
- **两者不能重复计入**

## 七、DCF 10 步法

1. 收集历史 FCF（OCF - CapEx）
2. 预测收入增速（基于行业/公司指引/历史趋势）
3. 预测利润率（基于成本结构/竞争格局）
4. 计算预测期 FCF
5. 确定 WACC（CAPM: Rf + β × ERP + 债务成本调整）
6. 折现预测期 FCF
7. 计算终值（Gordon Growth: FCF_n × (1+g) / (WACC-g)）
8. 折现终值
9. 计算 EV → 股权价值（减净负债/加净现金）
10. 敏感性分析（WACC × 终值增长率 矩阵）

## 八、估值质量自检清单
